# 0018: デザイントークンとテーマ（ライト / ダーク）

## 背景
画面の色は、`:root` のカスタムプロパティにあったが、ダークは OS の設定（`prefers-color-scheme`）に自動で従うだけで、切り替えられなかった。
余白・角丸・フォントサイズは、CSS にリテラルで散らばっていた。画面全体を白基調にして、ダークモードを利用者が選べるようにし、
文字の読みやすさ（コントラスト）と、選択状態の分かりやすさを保証したい。

## 決定
- **トークン**: `crates/web/style.css` の `:root` に、色（`--color-*`）・余白（`--space-*`）・角丸（`--radius-*`）・フォントサイズ（`--font-size-*`）・
  線の太さ・フォント・レイアウトの幅を定義し、各ルールは `var(--…)` で参照する。`[data-theme="dark"]` は、**色のトークンだけ**を、すべて上書きする
  （`color-scheme` も、`--color-scheme` トークンで切り替える）。**色は、トークン以外に書かない**（CSS のルール・Rust・`index.html`）。
  色名（`white`・`transparent` など）も使わない。
- **ライトは白基調**: ページ・カードとも白。カードは、淡い灰色の枠線で区別する。ヘッダー・コード欄・選択中の行だけが、ごく淡い灰色。
- **テーマの決め方**: `<html data-theme="light|dark">` には「決まった後の値」だけを入れる。利用者の選択は `light` / `dark` / `system`（既定）で、
  `localStorage` の `theme` に保存する。`system` は `prefers-color-scheme` で決め、OS の設定の変更にも追従する。
  **WASM の読み込み前**に配色を適用するため、`index.html` の `<head>` 内（スタイルシートより前）にインラインスクリプトを置き、先に `data-theme` を
  設定する（読み込みの間に、一瞬違う配色が出るのを防ぐ）。切り替えボタンの処理（`web::theme`）と、規則は同じ。規則の重複は、テストで、
  キー・属性名・置き場所の一致を確認して、ずれを防ぐ（node が無い環境でも動くよう、スクリプトの実行は自動テストに含めず、手動チェックリストで補う）。
  `localStorage` が使えないときは、`system` として扱い、画面は壊れない。
- **保存するもの**: `localStorage` に保存してよいのは、テーマの設定だけ。セッショントークン・投票内容など、これまでの方針（ブラウザに保存しない）は変えない。
- **切り替えボタン**: ヘッダーに「ライト / ダーク / OSに合わせる」の 3 つ。選択中は、`aria-pressed`・✓・太い枠・太字（色だけにしない）。
- **コントラスト**: 両方のテーマで、文字色と背景色（`text`・`text-muted`・`accent`・`danger`・`ok` を、`bg`・`surface`・`surface-alt` の上で。
  ボタンは `on-accent` を `accent` の上で）を、WCAG AA（通常の文字 4.5:1 以上）とする。枠線・フォーカス（`border-strong`・`focus`）は、
  文字ではない部品の境界として 3:1 以上（WCAG 1.4.11）。`web::theme` のテストが、`style.css` のトークンを読み、相対輝度から比を計算して確認する。
  色を変えて基準に届かないと、どのトークンの組み合わせかを示して失敗する。
- **選択状態を色だけで表さない**: 候補者の選択（太い枠・太字・「✓ 選択中」）、進捗（「✓ 済み / ▶ 今 / ○ これから」と「今」の左の太い線）、
  テーマの切り替え（✓・太い枠・`aria-pressed`）、エラー（先頭の「⚠」）、リンク（下線）。フォーカスは、太いアウトライン。
- **依存**: `web-sys` を `web` の直接の依存に足した（`Storage`・`MediaQueryList`・`Document`・`Element` の feature のため）。`leptos` の間接依存として、
  すでに同じ版（0.3.105）が使われているので、新しい版は増えない。

## 理由
- トークンだけに色を置けば、テーマの追加・色の調整が 1 か所で済み、コントラストの検証（トークンの組み合わせ）も、機械的にできる。
- 決まった値だけを `data-theme` に入れれば、CSS のダークの定義が 1 か所（`[data-theme="dark"]`）で済む（OS の設定用の `@media` を別に持たない）。
- ヘッド内の同期スクリプトは、描画の前に実行されるので、配色のちらつきが出ない。

## 代替案
- `data-theme` に `system` も入れ、CSS で `@media (prefers-color-scheme: dark)` と併用する: ダークの色の定義が 2 か所になり、ずれる恐れがあるので不採用。
- 選択を Cookie に保存する: サーバへ送られてしまうので不採用（ブラウザだけの設定）。
- コントラストを、ブラウザのツールで手動確認するだけにする: 色を直すたびに崩れるので、テストにした（目で見る確認は、補助として手動チェックリスト）。
